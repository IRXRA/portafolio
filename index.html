Caso 01 · Trazabilidad de activos

Plataforma de Control y Trazabilidad de Grifos

Desafío Operativo

La falta de visibilidad en tiempo real sobre el estado e histórico de mantenimiento de la red de grifos dificultaba la coordinación logística y la respuesta ante emergencias.

Solución Implementada

Lideré el diseño y desarrollo full-stack de una plataforma web para la gestión integral de activos, integrando bases de datos SQL, backend en Python/Uvicorn y un frontend para trazabilidad georreferenciada.

Impacto y Resultados

Optimización de tiempos de respuesta, digitalización del ciclo de vida del activo y centralización de la información para la toma de decisiones.

Python Uvicorn JavaScript SQL Georreferenciación
Arquitectura API REST y BD relacional
Output Visibilidad georreferenciada
Valor Operación Data-Driven
Caso 02 · Analítica Avanzada

Detección de Anomalías Hídricas y Fraude

Desafío Operativo

Las fallas de medición y fraudes generaban significativas pérdidas por Agua No Registrada (ANR), requiriendo un método proactivo para identificar irregularidades.

Solución Implementada

Desarrollé un pipeline de procesamiento masivo con Apache Spark y un modelado analítico integrado en un dashboard de Power BI (DAX) para el monitoreo de alertas.

Impacto y Resultados

Detección temprana de anomalías, mitigación de pérdidas financieras y focalización inteligente de recursos de inspección en terreno para maximizar el ROI.

Apache Spark Power BI DAX Modelado predictivo Data Pipeline
Arquitectura ETL y visualización
Output Alertas de comportamiento
Valor Recuperación financiera
